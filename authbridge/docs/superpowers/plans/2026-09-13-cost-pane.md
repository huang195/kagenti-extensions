# Cost Pane Implementation Plan (commit 8)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the numbers a home. One keystroke from anywhere opens a view that answers "on what did the money go, and is the figure trustworthy" — and remembers how you left it.

**Architecture:** Four tasks, one commit. A new pane on `$` renders five stacked sections from a `/v1/usage` snapshot. It computes nothing: every figure it shows is one the server settled, which is what the previous commit made possible. A small persisted UI state file remembers the window and grouping. The help overlay and footer gain entries — enforced by a coverage test that fails until they do.

**Tech Stack:** Go 1.x, bubbletea/lipgloss, standard library `testing`.

**Spec:** `authbridge/docs/superpowers/specs/2026-09-13-cost-first-class-design.md`

## Global Constraints

- **Module root is `authbridge/`.** Go commands from `.worktrees/cost-first-class/authbridge`; `git` from the worktree root.
- **`git commit -s` mandatory.** Trailer `Assisted-By: Claude (Anthropic AI) <noreply@anthropic.com>`; never `Co-Authored-By`.
- **abctl computes nothing.** No multiplication of tokens by rates, no dollar arithmetic beyond dividing published micros by 1e6 and computing percentages of a published total. The previous commit deleted the client-side pricing; do not reintroduce it. A percentage of two published figures is presentation, not pricing — that distinction is the line.
- **Never `$0.00` for an unknown value.** Unpriced reads "cost unavailable"; an agent with no tool inventory reads as nothing to report, never as a zero saving.
- **`AVOIDED` is never in the same column as money** and always carries its `est.` / `projected` marker. A counterfactual that renders like spend is the failure the whole container design exists to prevent.
- **All width arithmetic through `lipgloss.Width`.** `trunc` clips by runes and `truncStr` by bytes — **neither is display-cell aware**, and `footer.go:88-92` records the overflow bug that causes on wide characters. Do not use either for anything width-sensitive here.
- **Large or heavily-rewritten test files in SEVERAL SMALL tool calls**, never one big `Write`. A single oversized write exceeds this environment's stream watchdog and kills the agent deterministically; that already cost a restart on this branch.
- Do NOT run `make lint`. Do NOT `gofmt -w .` at the module root.
- Known pre-existing failure on this machine: `cmd/abctl`'s `TestRunExec_BeforeFirstStartRunsAndSaysWhatIsLost` (missing `~/.cortex/ca/bundle.crt`); fails on `main` too.
- Comment register: long comments explaining *why*, naming the bug the code prevents.

## Ruling made during planning: a third poll chain, deliberately

This pane needs its own window and grouping, so it needs its own snapshot. That makes **three** poll chains in the TUI — the Usage pane's, the spend strip's, and this one — each with the same sequence-guard shape.

Extracting a shared poller is the obvious response and is **deliberately not done here.** Refactoring the existing Usage pane's polling while simultaneously adding a pane means any regression in the Usage pane gets attributed to the new one, in the last commit of an eight-commit PR. Add the third copy, mark it, and file the extraction as its own focused change with the existing tests as its proof.

Copy the guard shape faithfully — `reqSeq` for stale replies, `tickGen` for stale chains. `usage_pane.go:64-79`'s comment records the bug it prevents: a quick exit and re-entry left two chains alive, each rescheduling the other's successor and doubling the request rate for the life of the session.

## Task 2: The five sections

**Interfaces produced:** `renderCostPane(snap *usage.Snapshot, group usage.Group, width, height int) string`, plus one unexported renderer per section so each is table-testable alone.

The five sections, in order: `TOTAL`, `BY <group>`, `WHERE THE MONEY GOES`, `AVOIDED`, `COVERAGE`.

- [ ] **Step 1: Write the failing tests, in several small calls**

Group them by the honesty rule each enforces, because that is what these tests are for:

**TOTAL** — shows requests, tokens, mean latency and cost; renders "cost unavailable" and no dollar figure when `snap.Priced` is false.

**BY \<group\>** — one row per series key with the four-way token split and cost; rows ordered by cost descending so the expensive thing is first (assert the order, since a map iteration would be nondeterministic and a table that reshuffles under the cursor is unreadable); a `(other)` overflow key renders like any other row; a series key of `""` is never rendered; non-inference requests carrying no model are disclosed as a count rather than folded into a row.

**WHERE THE MONEY GOES** — bars sized from the published per-tier micros; percentages computed from published totals only; **when `TierMicros` was absent server-side (a gateway's own figure cannot be split by tier without inventing the split) the section says the breakdown is unavailable and does NOT fall back to token proportions** — token share is not cost share, and presenting one as the other is the exact class of error this branch keeps finding.

**AVOIDED** — shows tokens and dollars avoided with the `est.` marker; shows `projected` distinctly (an unapplied prune must never read as money already not spent); renders **nothing at all** when `prunableRequests` is 0 — that is "no tool inventory to prune", not "saved nothing"; renders an explicit zero when `prunableRequests > 0` and nothing was avoided, because that IS a real zero; is never rendered in the same column as a cost figure.

**COVERAGE** — shows the priced/priceable gap and names the unpriced endpoint+model pairs from `UnpricedBy`; shows provenance shares from `PricedBy`; renders **nothing** when everything is priced from a single authoritative provenance — a permanent warning with nothing to act on is what teaches an operator to ignore the one signal that matters.

**Layout** — the whole pane at widths 120/100/80/64 and heights 40/24/20 never exceeds the given width and never emits a line wider than `width` (assert with `lipgloss.Width` per line); a small terminal drops whole sections from the bottom rather than clipping a number; no number is ever truncated mid-figure.
